# Tools 디렉토리

월급플러스의 추가 계산기들이 위치하는 곳.

## 추가 예정 도구 (우선순위순)

| 우선순위 | 파일명 | 도구명 | 이유 |
|---|---|---|---|
| 1 | `severance.html` | 퇴직금 계산기 | 검색량 매우 높음 + 메인 도구와 시너지 |
| 2 | `hourly.html` | 시급 계산기 | 알바·시간제 타겟, 주휴수당 포함 |
| 3 | `annual-leave.html` | 연차수당 계산기 | 연말·이직 시즌 트래픽 폭증 |
| 4 | `insurance.html` | 4대보험 계산기 | 사업주·인사담당자까지 타겟 확대 |
| 5 | `reverse.html` | 세후→세전 역산기 | 이직 협상 시 검색 |

## 새 도구 만들기

```bash
# 1. 템플릿 복사
cp _template.html severance.html

# 2. _template.html 안의 체크리스트 따라 수정

# 3. 부모 디렉토리의 sitemap.xml에 추가
#    <url><loc>https://example.com/tools/severance.html</loc>...

# 4. 부모 index.html의 "함께 쓰면 좋은 도구" 섹션에서
#    해당 카드의 class="tool-card coming"에서 'coming' 제거
#    href="#"를 href="/tools/severance.html"로 변경
```

## 각 도구 설계 노트

### severance.html (퇴직금 계산기)

**계산 공식**:
```
퇴직금 = 1일 평균임금 × 30일 × (재직일수 ÷ 365)
1일 평균임금 = 퇴직 직전 3개월 임금 총액 ÷ 3개월 일수
```

**입력 필드**:
- 입사일, 퇴사일 (날짜 선택)
- 최근 3개월 월 급여 (또는 평균 월급여)
- 연간 상여금
- 연차수당 (선택)

**주의사항**:
- 1년 미만 근속자는 퇴직금 없음 (안내 메시지)
- 1년 이상 근속 시 비례 지급
- 퇴직소득세 별도 계산 가능 (확장 기능)

### hourly.html (시급 계산기)

**계산 공식**:
```
주휴수당 = (1주 소정근로시간 ÷ 40시간) × 8시간 × 시급
주휴 포함 시급 = 시급 × 1.2 (40시간 근무 기준)
```

**입력 필드**:
- 시급 (또는 월급에서 시급 역산)
- 주 근무시간
- 야간/연장 시간 (선택)

**2026년 최저시급**: 매년 갱신 필요. 1월에 고용노동부 발표 확인.

### annual-leave.html (연차수당 계산기)

**계산 공식**:
```
연차수당 1일분 = 통상임금 ÷ 209시간 × 8시간
미사용 연차 보상금 = 연차수당 1일분 × 미사용 일수
```

**연차 발생 규칙**:
- 1년 미만: 1개월 개근 시 1일 (최대 11일)
- 1년 이상: 15일 + 3년차부터 2년마다 1일 추가 (최대 25일)

### insurance.html (4대보험 계산기)

**근로자·사업주 부담 동시 표시**:
- 국민연금: 근로자 4.5% + 사업주 4.5%
- 건강보험: 근로자 3.545% + 사업주 3.545%
- 장기요양: 건강보험료 × 12.95% (반반)
- 고용보험: 근로자 0.9% + 사업주 0.9~1.65% (규모별 차등)
- 산재보험: 사업주 100% (업종별 0.7~18.6%)

**차별화 포인트**: 메인 계산기는 근로자 부담만 표시. 이 페이지는 사업주 인사담당자 타겟.

### reverse.html (세후 → 세전 역산기)

이직 협상 시 "현재 실수령 350만원인데 연봉 얼마 받는 거?" 같은 검색 의도 공략.

**구현 방식**: 메인 계산기 로직을 역으로 — 이진 탐색(binary search)으로 추정.

```javascript
function reverseCalc(targetNetMonthly, dependents, children) {
  let low = 0, high = 500_000_000;
  while (high - low > 10000) {
    const mid = (low + high) / 2;
    const result = calcSalary(mid, 200000, dependents, children);
    if (result.netMonthly < targetNetMonthly) low = mid;
    else high = mid;
  }
  return Math.round(high / 10000) * 10000;
}
```

## 공통 디자인 원칙

모든 도구는:
- **3초 안에 결과**가 나와야 함 (입력 필드 최소화)
- **모바일 우선** — 한 손 조작 가능
- **메인 → 도구 → 다른 도구 → 메인** 내비게이션 명확
- **공유 버튼** 필수 (바이럴 트래픽 핵심)
- **광고 2개** 배치 (결과 직후 + 본문 중간)
