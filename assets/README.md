# Assets

이 폴더는 정적 자원(이미지, OG 이미지 등)이 위치합니다.

## 필요한 파일

- `og-image.png` (1200×630px) — 카톡·X 공유 시 미리보기 이미지
- `favicon.ico` — 현재는 index.html에 인라인 SVG로 처리. 필요시 PNG로 교체
- `apple-touch-icon.png` (180×180px) — iOS 홈화면 아이콘

## OG 이미지 만들기 (무료 도구)

- [Canva](https://canva.com) — 템플릿 풍부
